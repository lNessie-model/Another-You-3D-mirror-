## 修改与原因

V56 为保证闭口遮挡，保守恢复了两端牙冠，但中间八颗已缩短收窄。实测上牙两端比邻牙多向下伸约 1.69/1.66mm，端部 X 投影间隙约 0.91mm；下牙两端多向上伸约 0.96mm，端隙约 0.80mm，造成尖牙和断开感。

本版以牙冠自身坐标调整宽度和咬合端高度：中央切牙较宽，侧切牙略窄，犬牙不做长尖，两端前磨牙较短。上下每个相邻牙冠的 X 包围盒间隙约 0.12mm，保留圆弧轮廓和轻微牙缝，不把牙冠焊成一条白板。这个值是投影布局，不能当作精确三维曲面间距。

只修改两牙网格前 500 个顶点中归属牙冠的位置。原 80 个牙龈顶点、牙冠 Z、UV、顶点色、索引、所有头脸/眼睛/形变、8 个口角分离点和绑定参数保持。牙根 Y 锚点 float32 一致。`smooth-deformed-v1` 在真实 Java 首次更新时从新位置重算法线；保留的 NORMAL 用于分组身份，不会将旧法线直接用于新牙形。实际法线与独立重算最大角误差约 2.7e-6°。

额外唯一材质修改是共享 `WarmWhiteDentition` 的粗糙度 0.28→0.42，保留暖白顶点色、baseColorFactor 和 metallic=0，柔化亮部而不将牙齿变黑。该材质也用于牙龈，需一起看效果。现有内壁与舌头的 lit PBR 配色、全局光照、渲染代码和面捕映射均保持。
