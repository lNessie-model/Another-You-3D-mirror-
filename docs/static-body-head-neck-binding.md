# 固定身体与颈部过渡绑定标准

带有脖子、肩膀或上胸口的头部资产，统一按以下结构进入镜子运行时：

- `Root/StaticBody` 保持绑定姿态，身体、肩甲、衣领等不会被面捕头部角度带动。
- `Head` 是唯一接收 pitch、yaw、roll 的动态节点，旋转中心放在下颌下方的颈部连接处。
- `HeadNeck` 使用同一张连续表面裁切出的上部网格。裁切环在中立姿态与 `StaticBody` 共用位置；下缘权重为 1（保持世界位置），向上在过渡带内平滑降到 0（完全跟随 Head）。
- 六个 `headPoseCorrections` 目标按角度驱动颈部过渡：pitch ±20°、yaw ±30°、roll ±15°。运行时将它们作为普通 POSITION morph 处理并重新计算法线。
- 角度超过上述范围时只钳制校正目标，不扩大身体或肩膀的运动范围；资产仍需要在设备上做视觉验收。

这样处理的原因是当前设备导入器支持刚性节点和 morph，但不支持 glTF skin。把整张单网格挂在 `Head` 下会让肩膀一起转动；把身体和头部硬切成两个没有固定环的网格又会在转头时露缝。固定环校正目标保留单次网格上传和当前 20,000 顶点、30,000 三角形预算。

当前候选 `克劳德-静态身体-颈部校正-1536-v3` 的结构数据：身体 3,852 顶点 / 5,767 三角形，头颈 13,018 顶点 / 12,797 三角形，总计 16,870 顶点 / 18,564 三角形；材质图统一为 1,536² RGB PNG，满足设备 PBR atlas profile。

主机验证包括：实际 `AvatarGlbLoader` 通过、`AvatarRig` 角度到校正目标权重测试通过、身体网格在全部 51 个输入切换中保持不变，以及六个最大角度下裁切环最大数值误差小于 `8e-7`。这些是结构和数值门禁，不等同于艺术验收或所有角度的碰撞证明。

新模型导入时只需提供带材质的 GLB；流程会先合并/压缩到设备顶点预算，再按本标准测量裁切线、生成固定身体与头颈候选、保留中立/左右转头/低头预览，最后才进入设备私有预览。原始 GLB 始终只读保存。
