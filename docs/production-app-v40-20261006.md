# V40 / 0.2.9：详细调整页与返回流程

画面编辑按角色位置、头部朝向、立体景深、表情与镜像分组；保存、取消和保存错误固定在滚动区之外。三秒全屏预览暂时隐藏原生菜单，结束或关闭后恢复；取消和系统返回键恢复进入时的画面。相机校准按核对方向、建立基准、检查保存组织，预览区分别标记相机画面与角色动作。两个编辑窗口使用不透明黑金暗红样式，避免背后文字透出；相机预览与动作标签仅在文字变化时更新。

从独立设置页打开画面或相机校准，成功保存、取消或关闭编辑面板后直接回到设置；从魔镜运行页打开仍回到魔镜。保存失败不会关闭编辑页；生命周期暂停导致的关闭不触发额外页面跳转。相机编辑退出到设置时先释放预览，再停止运行输入和渲染，避免短暂恢复多视图。

保留原有明确保存事务、未来配置保护、相机输入身份验证、中性采集会话与 READY 检查、首帧请求门及资源停止确认。独立设置页仍不创建相机、面捕或 GL。模型、材质、渲染及推理算法、权限和依赖保持原版本。
