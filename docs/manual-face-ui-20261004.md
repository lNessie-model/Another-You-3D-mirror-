## 只想看不同表情

在“① 拖动数字，只预览表情”里拖 **左闭眼 / 右闭眼 / 张嘴 / 微笑**。
0是中性，1是完整表情。拖数字只改变预览，不会重做形态键。
此手工入口默认镜像关、强度1，名称中的Left是角色自己的左侧，正面看在画面右侧。

## 真正修改表情形状

1. 在“② 选表情，再修改顶点”里选择 **左眼闭合 (eyeBlinkLeft)**，点击 **进入表情形状编辑**。
2. 现在已进入编辑模式。滚轮放大闭合的那只眼，点击需要改的顶点；按 **G** 移动，左键确认，Esc取消。需要带动周围顶点时按 **O** 开启衰减编辑。
3. 点击 **完成形状编辑，返回预览**，或按 **Tab**。再拖闭眼数字到0、0.5、1检查形状。
4. 按 **Ctrl+Shift+S** 另存一份 `.blend`，保留交付原工程。

不要修改Basis、形态键名称、顶点数量、UV或材质。下方原生“形态键”列表仍可用；组合修正键是额外位移，操作说明见选定模型文档。
