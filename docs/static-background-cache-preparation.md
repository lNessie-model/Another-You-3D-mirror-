## 已实现

`AvatarDrawPartition` 按实际选中场景分类可绘制节点。无形变、没有头部／下颌／眼睛控制祖先且材质unlit的节点可进入初始静态候选集合。其余节点保持动态路径；普通ALL入口维持原节点顺序及每个节点一次绘制。

缓存恢复发生在动态绘制之后时，必须维持原始绘制顺序。只有原来全部静态候选都在动态节点之后，才报告canCacheTrailingBackground=true。静态节点原来在头像之前的场景不进入该初始缓存路径。对batch／VERIFY后端不开放split入口，原ALL及原batch流程保留。

`AvatarGpuScene` 已增加drawStaticBackground、drawDynamic入口，但InterlaceRenderer仍调用ALL；GPU缓存资源、缓存命中／失效逻辑、恢复shader和debug开关均未实现。因此没有新的GPU加速或新APK帧率结论。
