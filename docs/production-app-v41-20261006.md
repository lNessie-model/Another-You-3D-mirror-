## 实现范围

校准角色沿用真实所选 GLB、52通道绑定、原材质、姿态平滑与主场景自动 fit。原相机为多视点眼位、独立形变组合、围绕颈部的全方向旋转包围球留空，使杰洛特中性头部只占校准 viewport 的约30%宽/高。新校准透视单独读取 Head 子树的形变区间及眼球/下颌刚体包络，按已平滑的头部角度决定目标中心和视角；单纯眨眼或张口不触发变焦。它保留 distance 3、near .1、far 10、边距，不修改主多视图视差或材质。

校准中 Head 以外的静态场景允许裁切。此窗口用于查看动作；目标中心与视角随转头变化，不声称与主多视图逐像素相同。既有 PBR 视线向量约定保持。

相机与处理故障现在显示可操作说明，提供“重新连接相机”，沿原重试、原生资源停止及权限机制恢复。回调仅限当前校准面板、已恢复且未结束/销毁的 Activity。错误优先于旧输入身份；异常时取消采集、清除过期画面、撤销动作检查，禁止采集与保存。保存仍在 Host 内复核输入和 worker 身份。首次准备、健康相机但未见人脸、正常输入与故障分别处理；相同提示不反复更新文本。无输入时默认草稿按钮也禁用。

通用提示仅保证原安装设置不变。权限跳转或渲染故障重建可能丢弃未保存草稿；当前 HAL 故障下的本面板重试才在设备上验证了草稿/页面保留。
