# Another You V31 / 0.2.0（2026-10-05）

## 本版行为

原来的调试 Demo 新增正式的单启动入口：打开 Another You 后，首页显示当前角色和背景，一次点击进入魔镜。暗金属、酒红和暗金色主题沿用椭圆外壳；主要操作、菜单及选择弹窗置于屏幕中央安全区。

实时页面支持收起菜单、选择角色、场景与镜像设置、相机校准、设置及返回首页。画面设置保留原来的预览、保存和取消事务；返回键关闭当前层，不丢失已保存选择。相机流失败时显示明确的重试/检查 USB 提示，不把等待或相机错误显示成正在跟随。

角色库读取轻量目录和真实缩略图，选择后才加载一个模型。V31 包含杰洛特最终 stage13 校正版和原有参考向导，保留本地导入/恢复流程及十二种现有背景。其它模型正在逐项校正，本版没有把全库完成作为发布结论。角色页的“本机验证”仅指结构、加载和 GPU 验证，个人表情验收仍未通过。

## 实际验证

最终安装包完成首页、菜单、设置/关于页面、真实两角色切换、背景选择保存、选择弹窗取消和画面设置取消的设备检查。杰洛特模型 SHA256 为 `9381f452c53098314f97e1a1799ec55d2be37878e66bf205c7a26958afcef531`；参考向导为 `8349c9b7795a317c7f04cc5cb10d0fc4b2b53171689fe5d2e07965b4a5f1e407`。两者均由真实生产加载器获得有效 GL 首帧，没有以另一模型冒充切换成功。

切换后设备任务栈仅有一个 MirrorActivity；返回首页后运行 Activity 已退出，线程清单没有 Mirror Runtime、GLThread 或 AvatarPose worker，应用进程保留 Android 与 Mali 的系统线程。退出后 PSS 实测 130,526 KiB；这不是完整摄像头联合负载数据，也不能把系统 Graphics 栏的零值当作 GPU 内存归零证据。

实际 Android 控件检查确认十个完整滑条、背景选择框至少 48dp、主要按钮 52dp；滚动边缘的裁剪部分不当作完整触控目标。背景弹窗改用公开 Android API 的居中暗色列表，底部选项可见；取消不变更选择，离开页面关闭弹窗。高级参数选择沿用原监听和持久化路径。

相机校准在本次设备检查中加载同一杰洛特模型，预览最大 10FPS、不创建额外姿态 worker；校准打开时主交织帧计数停止，关闭后继续。这个检查通过的是预览与资源所有权，不能证明相机采集正常。

验收期间临时选择过冷蓝背景，最后已恢复暗红雾。`mirror-runtime.xml` 与 `mirror-scene-view.xml` 均与升级前备份逐字节一致：pitch 10 SUBPIXELS、tan 0.2777777、16 视点、400×640/视点、原比例/零平面/镜像响应未因升级改变。包内角色选择键新增为杰洛特，本地导入角色三槽状态保留。

构建、实际 SDK 编译、Catalog/Selection 97 项、UI/StartupGate 51 项、真实资产校准加载 16 项及相关生产 Java/管理/校准回归通过。主机测试使用实际 JSON 实现，GL 生命周期测试明确区分统计计数与真实当前 EGL 首帧。独立代码复核无待修复发布问题。

## 未完成范围

当前 USB 摄像头仍出现 `CAMERA_ERROR (3): Error configuring streams`，因此完整实时面捕、个人眉眼/微笑验收和完整联合负载没有通过。先前约 24.5FPS 采集属于本次较早的新会话，不能作为后来流错误已经恢复的证据。旧记录约 10.623FPS 的交织性能没有因本次 UI 工作变成 30FPS。

现有十种 IP 头部已清点：Geralt、Sephiroth、Maleficent、Gojo、Ada、Joker、Makima、Snape、Sukuna、Maul。其余九种的逐模型校正、质量验收和包内接入继续执行；已有 3D 背景也须单独验证加载及性能，不能以十二种二维/程序背景代替完成。艾达的自身拓扑、眉眼、嘴形和法线校正仍在本地进行，本版不打包未通过的中间成品。

五个离线预处理文件（profile、prepare_head、segment_face、包初始化及对应测试）以实验源码纳入。它们支持已知本地输入的显式坐标和逐模型 profile，不是通用可信输入或完整面部校正门槛；frontEvidence 的模型身份/SHA、相机中心有限数检查尚不完整，四项测试不表示艺术验收通过。实验输出及其它正在编写的管线文件不纳入 V31。

下一轮先完善模型自身的眉眼口组合、闭眼/闭口遮挡、材质与顶点/解码预算，再加入角色库并在设备上验证切换和实际渲染。每个通过的迭代按同一流程提交及普通推送，独立核对远端提交。
