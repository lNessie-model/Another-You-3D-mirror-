# V60 / 0.2.29：更从容的镜框揭幕与页面动效

V59 的启动揭幕只有 620ms，页面主要同时淡入，视觉节奏偏急。V60 将启动编排为 2.1 秒的有限序列：暗酒红光晕显影、金线从椭圆顶部沿两侧展开、中央徽记与中英文标题分段出现，随后镜框展开到首页轮廓、文字移动到实际首页位置，交接给首页操作区。

## 设计与行为

- 椭圆、细金线、暗酒红和衬线标题沿用现有魔镜风格。首页与 UI 页增加微弱光晕、菱形徽记和四向短刻线，内容仍位于椭圆安全区。
- 启动中的标题对齐实际首页文字的尺寸和基线，缓解交接时两个标题同时出现在不同位置的问题。启动 2.1 秒指动画本身，录屏从启动命令前开始，还包含设备冷启动时间；实际时长也受系统 Animator 倍率影响。
- 新建 UI 页的可见内容行使用 8dp 轻抬与淡入，持续 460ms，行间错开 35ms、最多 175ms，采用先启动后缓缓停稳的曲线。启动首页前三行由品牌文字接续，操作区随后浮现。屏外设置行不参与这组动画。
- 角色与素材图片过渡改为 420ms、0.982→1 微缩放。按钮按下 110ms、抬起/取消 220ms。弹窗进入 340ms、退出 220ms；原生窗口进入 420ms、退出 300ms，返回进入 360ms、退出 280ms。原有设备窗口和转场倍率 0.5 保留，因此窗口实际时间还会缩短。
- 同一次首次触摸立即结束揭幕和内容入场，继续交给原有控件，不要求等待动画结束。所有动画尊重系统关闭动画设置；暂停、移除或销毁时取消回调和属性动画，静置时不循环绘制。
- 实时交织窗口继续只使用 alpha 过渡；镜框的几何变化是 UI 覆盖层 Canvas 的绘制，不缩放或移动 GLSurfaceView。相机、NPU、表情、模型和材质保持本轮之前的实现。

## 验证与范围

离线 Gradle 编译成功，同签名覆盖安装 60 / 0.2.29。安装及 UI 检查前后，四份用户配置原字节保留。未刷机、root、重启、卸载或清应用数据。仅用 NEW_TASK / CLEAR_TASK 重新建立一次启动导航栈，未删除应用数据。

最终版本已录制真实设备上的启动、角色浏览、设置与关于弹窗。另行检查首次显示后点击跳过、三轮快速进出、后台恢复及暂停关闭弹窗、关闭系统动画时的导航、系统设置与有效默认 Animator 倍率恢复，以及静置时渲染帧计数稳定。检查结果和版本 APK 的哈希保存在本地本轮证据目录。

99 个 APK assets 与 9 个原生库逐字节匹配既有基线，无新增模型、个人录像或诊断向量。没有新渲染依赖、持续粒子或实时模糊。

本轮验收是原生 UI 动效与实际预览，不声称持续 60FPS，也未重测 USB 面捕、NPU 或 16+视点交织联合负载。GIF 的 20fps 是录屏时间采样设置，不是应用帧率。
