# V58 / 0.2.27：牙冠接触和黑槽修正

V57 的牙齿间距虽然收紧，正面仍有明显黑槽。本版调整现有牙冠前肩和侧缘，使实际设备画面里的主要暗槽减轻、牙列更连贯，保留每颗牙的细边界及原来的较小张嘴范围。

## 问题与修改

- 原来的 0.12mm 是 X 包围盒间距，不能证明可见牙面贴合。前肩点间距约 0.53～1.4mm，也不等于整个网格的可穿透牙缝；独立有限前投影检查的实际间隙中位约 0.13～0.15mm、最大约 0.68mm。牙侧凹退及独立牙冠法线的暗面共同放大了黑槽观感。
- 仅调整现有上下牙冠的局部 POSITION X/Z，保留 Y、根环、端帽中心点、后半轮廓、牙龈、拓扑、颜色、贴图、材质、节点、表情和绑定。最终 V4 相对安全 V3 仅补齐 Upper8 的八个 X 分量，最大追加 0.32015mm，24 个 BIN 字节变化，其 Y/Z 和其余模型内容保持。
- 暖白牙色、粗糙度 0.42，以及 0.8 jawOpen / 0.8 闭嘴乘积 / 12° 下颌附件均沿用 V57。没有修改面捕映射或渲染代码。
- 早期出现新增折面或闭口露牙的试验已拒绝，原记录保留；未推广为正式版本。最终接受的是固定的 V4。

## 验证与限制

最终候选的实际生产 Java 11 姿态检查：新增三维翻面、法线反例、退化及非有限值均为 0；720 个有限闭口探针绝对露牙数为 0。非牙冠和牙龈的实际 P/N 保持。独立代理核验 V3 四姿态，V4 再以一中性姿态和八 X 差异受限复核，未把作者闭口测试伪称为独立重跑。

辅助二维环检查保留一个 Upper8 row2 新凹转角：不是三维翻面，但不能称全部 80 环严格凸。正面 8→9 的有限投影中位间隙由 0.1504mm 变为 −0.1274mm，代表投影覆盖重叠，不代表三维接触或无碰撞；近根残余约 0.2074mm 和继承的 7→8 在 +20° 最大约 0.9646mm 仍保留。不宣称全部九对牙齿无缝、物理焊接、连续全角度闭口安全或完整解剖真实性。

Root 已查看实际 Mali 张嘴、微笑、闭嘴补偿及未改色的前后近景，接受本轮主要暗槽减轻、细牙冠边界保留。正式安装后运行 `347d2721-61a3-440c-8298-83277e705822`：317/317 项固定九姿态 ×16 层绘制检查通过；严格 serial/OVR RGBA 零差，individual/batch 在 RGB≤1、RMSE≤0.1、alpha 精确范围内，十张 PNG 全部完成。这是同一候选的绘制路径一致性验证，不是新旧模型像素零差。

升级为同签名覆盖安装。最终检查后十四份诊断文件及四份用户配置的内容与存在性精确恢复，回到 Home，无遗留测试临时文件或运行子进程。资源门核验 APK 中 99 个资产，仅四个批准修改，另外 95 个资产与全部九个原生库保持 V57 字节一致；未打包个人录像。没有清数据、卸载、重启、root 或刷固件。

本版没有重测联合帧率或实时摄像头效果，未声称 30FPS 达标、性能提升或整个产品目标完成。原面捕、交织、UI 和其它角色的历史证据保留。
